# Portfólio de Erik de Alencar

Bem-vindo ao portfólio pessoal de Erik, desenvolvido como uma apresentação moderna e responsiva para mostrar habilidades em front-end.

## 🚀 Sobre
Este projeto é um site estático de portfólio construído com:
- HTML
- CSS
- JavaScript

O objetivo é apresentar formação, experiência e links para redes sociais profissionais em um layout limpo e animado.

## 🧩 Páginas incluídas
- `index.html` — Página principal com apresentação pessoal e links para redes sociais.
- `sobre.html` — Página "Sobre mim" com descrição do autor e detalhes sobre estudos e objetivos.
- `css/main.css` — Estilos principais do site.
- `img/` — Imagens usadas no portfólio.

## ✨ Recursos
- Navegação simples entre páginas
- Animações com `animate.css`
- Fundo animado com `particles.js`
- Layout responsivo para diferentes tamanhos de tela

## 💻 Como usar
1. Abra a pasta do projeto no seu editor de código.
2. Abra `index.html` no navegador.
3. Navegue entre as seções usando o menu principal.
